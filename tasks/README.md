# tasks/README.md

# Engineering Backlog

This directory contains the complete implementation roadmap for AI Meeting Copilot.

The backlog is organized into incremental sprints.

Each sprint contains a collection of small, reviewable engineering tasks.

Development should always proceed sprint by sprint.

Never skip ahead unless explicitly approved.

---

# Task Format

Each task contains:

* Task ID
* Title
* Priority
* Estimated Effort
* Dependencies
* Description
* Acceptance Criteria

Example:

Task ID: T0001

Title:
Initialize Repository

Priority:
High

Estimated Effort:
15 minutes

Dependencies:
None

Acceptance Criteria:

* Repository structure exists.
* README is present.
* License is added.
* Initial commit completed.

---

# Development Rules

Implement only the tasks assigned.

Do not implement future sprint tasks.

Do not introduce additional features.

Do not change architecture without updating documentation.

Always keep commits small and reviewable.

# Completion Rules

A sprint is complete only if:

* All tasks are finished.
* Acceptance criteria are satisfied.
* Tests pass.
* Documentation is updated.
* Code review is complete.

Do not begin the next sprint until the current sprint has been reviewed and approved.
