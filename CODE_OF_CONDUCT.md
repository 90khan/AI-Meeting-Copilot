# Code of Conduct

# AI Meeting Copilot

## Our Pledge

We are committed to making participation in this project a respectful, welcoming and harassment-free experience for everyone.

Contributors should treat each other with professionalism, empathy and respect regardless of

* age
* nationality
* ethnicity
* religion
* disability
* gender identity
* sexual orientation
* technical experience
* education level

The project values collaboration, curiosity and continuous learning.

---

# Our Standards

Examples of positive behavior include

* Being respectful.
* Giving constructive feedback.
* Explaining technical decisions.
* Accepting feedback professionally.
* Helping new contributors.
* Sharing knowledge openly.
* Assuming positive intent.
* Respecting different opinions.

---

# Unacceptable Behavior

Examples include

* Personal attacks
* Harassment
* Hate speech
* Trolling
* Intimidation
* Deliberate misinformation
* Publishing private information
* Spam
* Disruptive behavior
* Discrimination

These behaviors are unacceptable in all project spaces.

---

# Technical Discussions

Technical disagreements are expected.

When disagreements occur

* discuss ideas instead of people
* provide evidence
* reference documentation
* consider trade-offs
* remain professional

Architecture decisions should be supported by ADRs whenever possible.

---

# Communication

When communicating

* be concise
* be respectful
* explain reasoning
* avoid unnecessary conflict
* encourage questions

Good communication improves software quality.

---

# Code Reviews

Code reviews should

* improve the code
* improve maintainability
* teach best practices
* identify risks

Code reviews should never become personal.

---

# AI-Generated Code

AI-assisted contributions are welcome.

However

* contributors remain responsible for submitted code
* generated code must be reviewed
* architecture rules still apply
* tests are still required

AI is an assistant, not the final reviewer.

---

# Enforcement

Project maintainers may

* request changes
* close inappropriate discussions
* remove harmful content
* restrict participation when necessary

These actions exist to protect the community.

---

# Scope

This Code of Conduct applies to

* GitHub issues
* Pull Requests
* Discussions
* Documentation
* Project communication channels
